## Outros pontos de entrada

| Onde | Link |
|---|---|
| Link da bio do Instagram | `https://www.clubedocardapio.com.br/?utm_source=instagram&utm_medium=bio` |
| Story (arrastar/figurinha de link) | `https://www.clubedocardapio.com.br/?utm_source=instagram&utm_medium=story&utm_campaign=NOME-DA-CAMPANHA` |
| Anúncio no Instagram/Facebook | `https://www.clubedocardapio.com.br/familias/?utm_source=meta&utm_medium=anuncio&utm_campaign=NOME-DA-CAMPANHA` |
| WhatsApp (mensagem enviada a cliente) | `https://www.clubedocardapio.com.br/?utm_source=whatsapp&utm_medium=mensagem` |

Regras para criar links novos:
- tudo em letras minúsculas, sem acento e sem espaço (use hífen);
- `utm_source` = de onde veio (instagram, meta, whatsapp);
- `utm_medium` = o formato (manychat, bio, story, anuncio);
- `utm_campaign` = o nome da ação (ex.: `lancamento-outubro`);
- `utm_content` = o detalhe (ex.: qual botão ou qual público).

## Mensagens sugeridas para o fluxo

1. Gatilho: comentário ou mensagem com a palavra **CARDÁPIO**.
2. Mensagem 1: "Oi! 😊 Que bom te ver por aqui. Para quem é o cardápio?" com os 3 botões acima.
3. Mensagem 2 (após o clique): "Perfeito! Aqui está a página com tudo sobre o cardápio {público}: o que vem, os preços e como funciona. Qualquer dúvida, é só responder aqui." + botão com o link.
