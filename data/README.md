# Dados do MVP

Esta pasta contém o modelo mínimo de dados da Fase 3:

- `schema.sql`: tabelas, chaves, restrições e índices;
- `seed.sql`: produtos e cardápios demonstrativos.

Os preços estão nulos de propósito, pois serão definidos pela proprietária. As refeições são placeholders técnicos e não representam orientação nutricional. O conteúdo real deve ser importado somente após ser fornecido pela Rita.
